Sistema de Pedidos para um Food Truck

Projeto desenvolvido em Kotlin para a disciplina de programação.

Funcionalidades

- Escolha de produtos.
- Cálculo do valor total do pedido.
- Aplicação de desconto.

Linguagem utilizada

- Kotlin.
Como executar

1. Tenha o Kotlin instalado ou utilize o IntelliJ IDEA.
2. Abra o arquivo "truk.kt" no ambiente de desenvolvimento.
3. Execute o programa.
4. Digite seu nome e escolha os produtos no menu.
5. Informe as quantidades e digite "0" para finalizar o pedido.

Autor

Projeto desenvolvido para a atividade prática de programação em Kotlin.
